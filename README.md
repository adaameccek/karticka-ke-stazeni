# Kartička

Appka na věrnostní karty: podle polohy pozná obchod a ukáže jeho kartu. Karty zůstávají jen v telefonu.

**Vyzkoušet na webu:** https://karticka.adamhorak.cz

## Stažení pro Android

Nejnovější verze je v sekci [Releases](https://github.com/adaameccek/karticka-ke-stazeni/releases/latest) jako soubor `karticka.apk`. Stáhni ho v telefonu, otevři a povol instalaci z tohoto zdroje.

## Kód

Zdrojový kód je tu k nahlédnutí a ke stažení. Úpravy dělá jen autor, navržené změny (pull requesty) se nepřijímají.
